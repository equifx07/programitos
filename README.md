# Programitos 🤖💞🐱

Juego web de **programación secuencial para 1er grado**, pensado para jugar **de a dos en la misma compu**.

- Cada chico maneja un personaje: **Tito** (izquierda) y **Lula** (derecha).
- Arman la secuencia de flechas de su personaje y el programa corre cuando **los dos** aprietan LISTO.
- 12 niveles: secuencias → direcciones → cooperación (uno abre la puerta del otro) → bloque **repetir**.
- Voz que lee las consignas, sonidos, pistas con huellitas, álbum de figuritas y festejo con "chocá los cinco".
- Modo docente (🍎 en el mapa): desbloquear niveles, borrar progreso, ir a un nivel.

Teclado: Tito `W A S D`, `R` repetir, `Q` borrar, `E` listo · Lula flechas, `Shift der.` repetir, `Backspace` borrar, `Enter` listo.

Sitio estático (HTML/CSS/JS sin dependencias) servido con nginx (`Dockerfile`).
